## Phase 1 — Correctness audit, proof audit, and frozen protocol (13–16 September; abstract by 18 September)

**1. Reconcile E0 before retaining any scientific counts.** Build one run-level source-of-truth table from raw trajectories and frozen configs. Recompute each run's nondegenerate weak-only first hit, response gap **at that hit**, any-time negative gap, signed and positive-part weak-AUC deficit, threshold-delay status, crossing subtype, and censoring. These are different endpoints. The current `paper/main.tex` definition requires `Delta(tau_W*) < 0`, whereas the attached proof's E10 uses a negative gap at *some* positive time. Neither a positive signed AUC nor a passing gate alone proves the paper's at-hit certificate. The existing `classify_causal_regime` uses a delay band, another distinct label. Choose and freeze one primary definition; retain the others under explicit names and re-check the theorems' conclusions against it. Recompute all dense-RNN cells, tanh 3/8 versus five “suppression throughout” records, GRU crossings and failed gates, and every affected caption/table/plot. An earlier sign reversal is an equivariance check, not a no-cue negative control. Add exact identical-input/ablation tests. **Hard gate:** any unresolved contradiction removes the associated quantitative claim from the abstract and paper.

**2. Audit the attached proof independently.** Map every proposed theorem to its exact assumptions, statement, proof, manuscript claim, and available code. Check the hitting-time regularity repair (absolute continuity or stronger), common B/W response function at shared initialization, parameter chart, full-batch gradient-flow/GD assumptions, smoothness or fixed ReLU activation, horizon and margin sizes, and whether the new at-hit definition is actually established. Reproduce the exact rational/interval certificates using the companion `code/reproduce.py`, verifier, configs, and certificate files **if the authors supply them**; those files are not present in this repository. Independent mathematical review and code-to-equation checks remain necessary. If artifacts are unavailable or verification fails, state the analytic conditional theorem separately and do not advertise the computational examples as reproduced. Report the proof's nonvacuity limits prominently: certified response margins around `1e-7`, roughly `1e-4` of contemporaneous weak-only levels, no classification error on its noiseless probes, and 0/30 plus 0/25 certificates in the reported parameter sweeps. These are existence results, not evidence of typical CIFAR behavior.

**3. Freeze a lean CIFAR protocol before looking at B.** Create a new machine-validated preregistration and content-addressed environment/source manifest. The existing `submission_claim_set.yaml` explicitly forbids new confirmatory outcomes until a reviewed clean source state, locked environment, pre-outcome committed preregistration, and untouched seeds exist; satisfy and update that governance gate first. Do **not** edit or repurpose the existing semi-real preregistration. Specify one architecture (proposed: a small four-block GroupNorm CNN; select it using W-only competence and pilot runtime only), CIFAR-10 image-level split, deterministic augmentation, optimizer, update/epoch budget, batch order, checkpoint grid, seeds, all metrics, thresholds, exclusion rules, and one analysis script. Append a removable cue ribbon *outside* the original 32×32 core, preserving every core pixel. B receives label-correlated codes; W receives a neutral, exactly zero-valued cue channel after preprocessing. Reuse identical initial weights, optimizer configuration, image order, augmentation randomness, and core tensors for each pair. Evaluation-only random and wrong codes do not create extra training arms. Run a same-input null test; consider a cheap strong-only pilot to confirm cue learnability, but do not select cue strength by maximizing B–W deficits.

Calibrate only W pilots and separate cue-only feasibility pilots. Freeze target `beta`, response scale `S`, horizon `H` measured in optimizer updates/examples processed (not continuous gradient-flow time), cue reliability/amplitude, model, training budget, competence minimum, and confirmation seeds before inspecting B. Prefer class-balanced Brier skill on a fixed common neutral/core diagnostic set as the weak-response measure; report accuracy and cross-entropy as behavior. Define the W gate nondegenerately and treat failure as **indeterminate**. Record predeclared materiality thresholds as design targets rather than post-hoc significance filters (for example, normalized signed deficit at least 0.10, deficit at least `0.10 S` for at least `0.10 H`, and at least five percentage points neutral/conflict accuracy harm). Report continuous estimates and uncertainty even when these targets fail. Fix whether the primary certificate is any-time or at-W-hit and use the same convention in code, proofs, tables, and abstract.

## Phase 2 — One-architecture CIFAR confirmation, behavior, and E4-lite (16–22 September)

**4. Execute the matched confirmation.** Use eight *fresh* paired seed blocks, disjoint from calibration and pilots, with one B and one W run per block. A block fixes initialization, cue-code mapping, image/augmentation order, and other random streams; report precisely which sources vary and never count checkpoints or test images as independent training replicates. If stochastic train updates differ because B changes the training path, the sample stream and RNG must still be matched. Store initial/checkpoint hashes, transformed-input equality checks, raw logs, exact config, code/environment commit/hash, and completion/failure flags. Run only the frozen cell. A short B/W debug pilot before the freeze is allowed, but its outcomes are exploratory and excluded from confirmatory uncertainty.

**5. Evaluate behavior on those exact eight pairs.** On the same held-out images, score neutral/core inputs, uniform random cues, label-consistent cues, and conflict cues (average the nine wrong-code versions *within each source image* before aggregating). At every frozen checkpoint compute B–W weak response `Delta(t)`, signed AUC/deficit, positive-part deficit, first-hit/gate status, minimum gap, and contiguous duration below the prespecified material threshold. At the final checkpoint report paired neutral, random-cue, and conflict accuracy, Brier skill, and cross-entropy. Use seed-level paired effect estimates, individual seed plots, and 95% confidence intervals; eight seeds are modest evidence and do not justify prevalence claims. If several distinct endpoints are confirmatory, prespecify a joint/conjunctive success rule or multiplicity correction; do not choose the winning metric after seeing results. Explicitly report null results, gate failures, and incomplete runs.

**6. Run E4-lite at final checkpoint `H` only.** Freeze each B and W encoder and buffers. Extract features for identical neutral/core inputs from a disjoint probe-fit set; fit a fresh, class-balanced linear softmax head with identical architecture, regularization grid, optimizer, initialization/restart policy, tuning budget, and preprocessing. Fit feature normalization on probe-fit data only; choose hyperparameters on validation, then evaluate once on held-out data. Compare original-head and fresh-head B–W gaps within seed. If the original-head gap disappears, conclude **readout underuse**. If it remains after fair linear probing, conclude **reduced linear accessibility under this probe**, not information loss; a nonlinear decoder would be needed for any broader representational claim. Report probe convergence, training set size, hyperparameters, and uncertainty. Do not retrain the encoder in E4-lite.

**Phase-2 deliverables/gate:** reproducible dataset-generation/training/evaluation code; eight complete B/W trajectories or transparently reported incompletes; paired behavior and E4 tables/figures; schema and matching tests. A strong practical conclusion requires a passing W gate, material persistent deficit, a prespecified behavioral disadvantage with paired uncertainty favoring W, and an E4 interpretation that is accurately worded. If only the response gap appears, state a learning-efficiency/response result. If E4 recovers the gap, do not claim representational starvation. If W cannot learn or the core accuracy is poor, the selected cell is not a valid causal image demonstration.

Rebuild every table/figure from pinned artifacts; run the full test suite, proof verifiers if available, LaTeX build, page-count/anonymous metadata checks, source-to-figure audit, and independent coauthor proof/readout review. Complete the mandatory AI-use statement and optional reproducibility statement. Submit a **genuine, conservative abstract by 18 September** based on established results; update it before the paper deadline only with confirmed outcomes. Reserve the final day for upload and verification rather than starting a new experiment.
